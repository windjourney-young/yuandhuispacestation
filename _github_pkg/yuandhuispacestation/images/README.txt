==================================================
  地球 · 星际相册 —— 图片存放说明
==================================================

把你想在「🌏 地球」弹窗里展示的图片放进这个文件夹即可。

支持格式：.jpg  .jpeg  .png  .webp  .gif  .bmp
建议尺寸：横图，900x600 左右（更大的图会自动缩放显示）
命名建议：用英文或数字命名，如 trip-01.jpg、family-2024.png
        避免用纯中文或特殊字符，以防个别浏览器加载失败

--------------------------------------------------
同步到网页的步骤
--------------------------------------------------
1. 把图片放进这个 images/ 文件夹（增删都行）
2. 双击运行 tools/gen_album_manifest.py
   （或在命令行执行：python tools/gen_album_manifest.py）
   → 它会自动扫描本文件夹，更新 js/album-manifest.js 清单
3. 把 images/ 文件夹和 js/album-manifest.js 一起提交到 GitHub
   （具体操作见项目根目录的「日常更新同步指南.html」）
4. GitHub Pages 1-2 分钟后自动更新，刷新网页即可看到新相册

--------------------------------------------------
注意
--------------------------------------------------
• 本文件夹已自带 8 张示例图（sample-01 ~ sample-08），可直接删除替换
• 不要把 .txt / .md 等非图片文件留在这里，脚本会自动忽略
• 子目录里的图片不会被扫描，请把图片直接放在本文件夹根下
